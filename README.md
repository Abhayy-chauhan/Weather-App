# 🌤️ Weather App

Welcome to the **Weather App**! This application provides real-time weather information based on your current location or any city you specify.

🔗 **Live Demo:** [https://abhayy-chauhan.github.io/Weather-App/](https://abhayy-chauhan.github.io/Weather-App/)

---

## ✨ Features

* **📍 Automatic Location Detection:** By allowing location access, the app automatically fetches and displays up-to-date weather details for your current position.
* **🔍 City Search:** Easily search for any city worldwide to get instant weather updates—perfect for traveling or checking conditions for friends and family.
* **📊 Key Weather Metrics:** Get detailed insights including:
  * Temperature
  * Cloud cover
  * Humidity levels
  * Wind speed

---

## 🚀 Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript (Vanilla)**
* **OpenWeatherMap API**
